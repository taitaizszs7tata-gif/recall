# Recall

Recall 是一个碎片化信息整理助手的静态网页原型。它支持粘贴文字、上传截图、AI 整理收藏内容，并提供语义检索和知识库视图。

## 本地运行

这个项目是单文件静态页面，不需要安装依赖。

```bash
python -m http.server 4173 --bind 127.0.0.1
```

启动后访问：

```text
http://127.0.0.1:4173/index.html
```
